# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по SemVer.

## [Не выпущено]

Прошивка lostOS 0.3.7 и сервер.

### Новое
- **Колонка узнаёт, кто говорит, сама.** Голосовой отпечаток считается прямо на колонке по моделям, которые уже есть в её прошивке Яндекса. Серверу больше не нужен SpeechBrain для этого, а старые голоса дописываются сами, перезаписывать их не надо (кроме тех, кого сервер не узнаёт)
- **Плагины Luna работают в lostOS.** Скрипты на Lua запускаются на колонке, пакеты `.yap` ставятся из панели. Плагины-программы (например, uwu-eyes с глазами на часах) работают так же, как обычные: ты разрешаешь им запуск и включаешь. Страница такого плагина открывается прямо в панели
- **Общий ffmpeg для плагинов.** Плагинам, которым нужно перекодировать звук, он теперь доступен на колонке
- **Часы.** У колонок без часов в панели нет страницы «Часы и подсветка». Появился переключатель «Автояркость»: выключи, и часы всегда горят выбранной яркостью, без затемнения по датчику света
- **SoundCloud.** Плагин с поиском, очередью, плиткой в «Пункте управления» и избранным по ссылке на профиль
- **Звук сервера на колонке** с названием и обложкой (для плагинов сервера)
- **Радио, оформление, обновления, плагины.** Плагин «Интернет-радио» со своей страницей, темы оформления в панели (Стекло и Material 3), страница «Обновление ПО» с автообновлением, выбор слова активации (Алиса, Яндекс, Yasmina), подключение любого OpenAI-совместимого сервиса при первой настройке
- **Бот Telegram переделан.** /start открывает пульт: что играет, трек вперёд и назад, громкость, выбор колонки в доме
- **Свои страницы у плагинов** и плагины на JavaScript прямо на колонке

### Исправлено
- **SoundCloud больше не «откатывает» паузу.** Раньше после паузы или стопа плагин через время сам включал следующий трек
- **Telegram-бот на общем сервере** давал каждому вошедшему права хозяина. Теперь каждый видит только свой дом
- **Чужие данные в промпте.** В общем тексте ассистента было имя владельца, из-за чего чужие колонки называли людей его именем. Убрано
- **Станция 1:** слово активации срабатывает вовремя, а не после всей фразы (раньше фраза терялась)
- **Плагины.** Установка или удаление одного плагина больше не останавливает остальные, голос из плагина не пропадает из списка, у обновлённого плагина не слетает включение, если он не просит новых прав
- **Память в админке.** «Память сейчас» и пик больше не считают файловый кэш: там показывается только то, что реально занимает процесс
- Бот перестал молча проглатывать ошибки Telegram, поэтому «бот не отвечает» теперь видно в логе

### Безопасность
- Плагины не получают ключи и окружение сервера, только своё
- На общем сервере работают только плагины, подписанные командой lostOS
- Проверка пакетов плагинов строже (число записей, повторяющиеся пути)
- Клиенты облачного голоса Яндекса не попадают в публичный репозиторий читаемым текстом

### Известные ограничения
- Новое распознавание голоса проверено вживую на Мини 3 и Станции 1 на одном человеке: если колонка путает людей, поднимите `VOICE_VP_THRESHOLD` (по умолчанию 0,78)
- Лайт 1: тишина колонки пока не исправлена, нужны данные от её владельца

## [0.1.0] — 2026-10-25
Первая версия под именем lostOS.

### Добавлено
- Панель lostOS (PWA, iOS-26 Liquid Glass): телефон и ПК, HTTPS со своим сертификатом, web-push уведомления.
- Будильники как в iOS, таймеры, напоминания, сценарии (голос, расписание), таймер сна, умный дом (Home Assistant).
- Движки распознавания и озвучки: облако Алисы по умолчанию, Whisper и Silero по желанию.
- Обложка из потока AirPlay, лайк только для Spotify, громкость Spotify/Bluetooth связана с главной.
- Звук громкости с выключателем, проверка состояния служб, резервная копия.

### Исправлено
- Отсчёт до будильника в панели обновляется каждую секунду.
- Сценарии со словами, которые облако маскирует звёздочками.
