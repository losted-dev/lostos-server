# Alice API

Голос и слух Алисы. Озвучка и распознавание речи идут в облако Яндекса, поэтому нужен интернет, а тексты ответов и записи вашего голоса туда уходят.

## Кто этим пользуется
- **Мозг lostOS** произносит ответы голосом Алисы и слушает вас через этот плагин.
- Любой плагин с разрешением `alice.api` («Голос и слух Алисы») может озвучить текст или распознать запись.

## Выключить
Без Alice API озвучка и распознавание работают только через другие движки: локальные Silero и Whisper (если вы их установили в настройках голоса) или плагины с `speech.tts` и `speech.stt`. Если ничего этого нет, колонка не услышит вас и промолчит в ответ.

## Для разработчиков
Плагин на сервере вызывает методы через `lostos_sdk.call`, например `lostos_sdk.call("alice.tts", text="Привет")`:

| Метод | Что передать | Что вернёт |
|---|---|---|
| `alice.tts` | `{"text": "Привет"}` до 1000 знаков | `{"pcm_b64", "rate"}` 16 бит, моно |
| `alice.stt` | `{"pcm_b64"}` 16 кГц, 16 бит, моно, от 0,1 до 30 секунд | `{"text"}` |

Нужно разрешение `alice.api` в `manifest.json`.

Владелец может выключить Alice API в любой момент. Тогда оба метода возвращают ошибку «alice-api выключен владельцем». Плагин должен её перехватить (в SDK это исключение `PluginError`) и сделать что-то другое, например вернуть ответ текстом. Если ошибку не перехватить, плагин упадёт на ровном месте.
