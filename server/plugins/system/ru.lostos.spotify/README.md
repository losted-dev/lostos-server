# Spotify Connect

Колонка становится устройством Spotify. Откройте приложение Spotify на телефоне, коснитесь значка «Устройства» и выберите колонку по имени. Входить на самой колонке не нужно.

## Что нужно
- Аккаунт **Spotify Premium**. Без него Spotify не разрешает управлять чужим устройством.
- Телефон и колонка в одной сети Wi-Fi (для первого подключения).

## Что умеет
- Играет до 320 кбит/с, показывает трек и обложку на странице «Сейчас».
- Голосом и кнопками: «поставь паузу», «дальше», «включи». После долгой паузы, когда Spotify сам забыл колонку, сервер разбудит её через Web API.
- Ползунок громкости в Spotify двигает громкость колонки.
- Пока ассистент слушает или отвечает, музыка приглушается и возвращается.

## Выключить
Переключатель на этой странице убирает колонку из списка устройств Spotify, останавливает музыку из него и убирает плашку Spotify с главной (она принадлежит этому плагину). Выбор остаётся и после перезагрузки; вход в Spotify при этом не стирается.

## Как это устроено
Это системный плагин lostOS: приёмник работает на самой колонке, его запускает и перезапускает прошивка. Войти в Spotify для поиска песен голосом можно в разделе «Ключи».
